# Smart Hackathon Management Platform

## Overview
The Smart Hackathon Management Platform is a web-based system designed to automate and streamline the complete lifecycle of hackathons. It enables efficient management of registrations, verification, team formation, submissions, shortlisting, offline event operations, and certificate distribution.

## Features

### Student Module
- Explore and register for hackathons
- Team creation and joining via unique team codes
- Upload initial submissions (PPT, resume)
- View shortlisting results
- Participate in offline events using QR-based entry and meal tracking
- Submit final project (GitHub, deploy link, final PPT)
- Access and download certificates
- Raise queries via in-app help system

### Organizer Module
- Create and manage hackathons
- Review AI-ranked submissions
- Shortlist teams for offline rounds
- Allocate workspace and manage event timeline
- Generate certificates using templates
- Monitor participant activity and QR scans

### Admin Module
- Verify organizers
- Approve or reject hackathon events
- Monitor platform activity

## System Workflow
1. Student registers and completes verification
2. Student explores hackathons and forms/join teams
3. Initial submissions are uploaded and evaluated
4. Shortlisted teams are notified
5. Offline hackathon is managed via QR-based system
6. Final submissions are collected
7. Certificates are generated and distributed

## Tech Stack

- Dynamic UI rendering based on hackathon stages
- Centralized dashboard for activity tracking
